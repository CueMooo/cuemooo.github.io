THE LOCKER

Devin's unofficial arcade. Add a game file, add a line to games.json, done.

How to add a game

  1. Download a game from one of the GitHub repos in README.md.
  2. Put it in games/ (example: games/slope/index.html).
  3. Add one object to games.json.
  4. Push. The list updates itself.
